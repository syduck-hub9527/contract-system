# 币安合约 5 分钟 DIF 实时监控

实时扫描所有**交易中的永续合约**（默认 U 本位 + 币本位），计算：

- `EMA21`、`EMA50`、`EMA200`，均基于**5分钟收盘价**。
- `DIF = EMA21 - EMA50`。
- 价格归一化 `DIF% = (EMA21 - EMA50) / 最新价 × 100%`，用于不同币价之间的筛选。
- **盘中金叉 / 死叉**：当前**尚未收盘**的5分钟K线，DIF已经越过零轴；可能反复改变。
- **确认金叉 / 死叉**：5分钟K线已收盘，DIF相对前一根已收盘K线越过零轴。最近5分钟的确认信号可见。
- 价格高于还是低于 EMA200，用于辅助判断趋势；默认不强制过滤。

## 交叉前概率研究（第一版）

保留原有雷达，新增页面顶部的研究面板。**不自动下单，不保证盈利**。目前只对你选择的U本位USDT永续合约进行研究，币本位继续提供行情监控。

### 使用方法

1. 按下方方法启动，等所选合约载入行情。
2. 顶部填写交易对（默认BTC、ETH、SOL、BNB，最多8个）、历史数量、近零阈值、止损/止盈ATR倍数、持仓期限、手续费与滑点，点击 **运行历史验证**。
3. 历史数量默认每币10000根，约34.7天；最多20000根，约69.4天。下载公开5分钟OHLCV及对应资金费历史，后台运行，不阻塞网页。新上市合约可能只有更少历史。实际覆盖、缺口、失败合约均显示。
4. 查看时间外测试结果以及 **提前进场 / 等待确认进场** 对比。只有满足可靠性门槛才会显示当前候选概率，否则显示“暂无法可靠估计”。这是研究结论，不是入场许可。
5. 如需参考仓位，填写账户权益与单笔风险预算。数量未按交易所规则取整，不可直接用于下单。

### 两种概率的含义

- **交叉概率**：在上一根5分钟K线收盘时，DIF接近零轴且正在向零轴靠近，下一根收盘能否跨轴。
- **净盈利概率**：在同一观察时刻，假设下一根开盘进场，以观察时的ATR设置止损/止盈，最多持仓指定根数，到期平仓，扣除双边手续费、滑点和持仓期历史资金费后是否盈利。
- 当前盘中实际价格进场、交叉已发生后的进场、不同止盈止损规则，都不适用页面概率。候选显示观察收盘时间与参考收盘价，实际模拟入场使用下一根开盘价。
- **交叉触发价**由EMA公式精确求解，表示下一根收盘达到该价格时DIF为零；不表示价格一定能到达。

### 特征与验证

第一版使用8个可解释特征：DIF/ATR、DIF变化/ATR、价格距EMA200/ATR、EMA200斜率/ATR、过去15分钟与1小时价格变化/ATR、相对20根成交量、ATR/价格。15分钟和1小时特征是过去3/12根5分钟的价格变化，**不是尚未收盘的高周期K线，也不是独立高周期EMA**。ATR使用Wilder递推14，方向归一化后合并多空样本。

采用标准库实现的带L2正则逻辑回归，并在独立中间时间段做sigmoid概率校准，无新增Python依赖。所有币种共用按观察时间计算的60%训练/20%校准/20%测试边界，剔除结果窗口越过边界的样本；同币候选窗口不重叠。训练数据决定特征均值与缩放，后续数据不会反向影响先前特征。

显示概率的门槛：

- 训练≥200、校准≥80、测试≥80，且各段正负两类各≥15。
- 样本外Brier分数（越低越好）优于训练期固定概率基线。
- 当前预测所在20个百分点宽的测试区间≥30例，平均预测与实际比例差≤15个百分点。
- 当前特征不超出训练均值±5个标准差；行情更新时间≤90秒，最近收盘历史有效；未处于重同步或重新验证中；验证完成≤24小时。

这些门槛是保守的展示规则，**不等于统计显著盈利证明**。区间为测试样本比例的描述性95% Wilson区间，未校正币种间和时间相关性，不是下一笔真实概率的置信区间。观察值不同于训练分布、近期行情变换和未来资金费都会导致估计失效。反复修改参数挑选最好的测试结果会使测试失去独立性，应另留更长历史并模拟盘前向检验。

### 成交、成本与对比的边界

- 止损/止盈以含入场滑点的成交价为基准，间距使用观察时ATR；下一根开盘成交。退出也施加不利滑点，开平仓各收单边费率。
- 同一根K线同时触及止盈止损，保守按止损；后续开盘跳过止损按开盘价成交；到期按收盘价平仓。缺失K线不合成研究样本，缺口后重新预热。
- 资金费使用该合约实际历史结算时间与费率，方向正确计入收付，以相应5分钟开盘价近似结算名义价值；这不是交易所逐笔精确账单。未来费率未知。
- 只有下一根确实交叉的候选才进入“等待确认”组，确认后再下一根开盘进场。并列提供这组候选的提前进场结果，避免把不同样本混为同一对比。
- 各币种独立模拟，尚未建模组合仓位、强平、保证金、订单簿深度或可成交量。页面均值基于每笔名义仓位，不是账户收益曲线。第一版没有盘中历史概率、真实账户交易记录或组合最大回撤。
- 手续费默认单边5 bps、滑点默认单边2 bps只是试验假设，1 bps=0.01%；须改为实际费率并测试更差滑点。参考仓位按止损距离加双边成本预留倒推，默认风险预算0.25%；极端滑点、跳空及资金费可能超出预算。

模型与报告保存在本机 `research_cache.json`（已加入gitignore），重启可恢复，超过24小时停止显示概率。历史原始K线和真实交易明细不持久化；若下载失败，页面列出失败原因。每次修改参数并运行都会替换本机上次报告，请先记录需要保留的实验参数和结果。

## 运行原理

- 启动时：REST 获取永续合约名单，每个合约获取499根5分钟K线，以便计算EMA200，并显示初始化进度。
- 历史载入期间：逐批建立 WebSocket 订阅（不是反复下载CSV/Excel）。
- 运行时：币安有新的K线数据就重新计算**盘中临时 DIF**；K线收盘 `x=true` 后再计算确认信号。
- 浏览器：**每2秒**读取本机实时状态。网页版无需重新打开或按刷新。
- 网络断线：WebSocket 自动重连；若有错过的整根5分钟K线，会使用REST重新同步，以免假信号。
- 时钟校准：启动时读取币安服务器时间，用它判断K线是否收盘，本机时钟快慢不会影响EMA。
- 无成交的K线：币安不返回没有成交的5分钟K线，程序按图表软件的做法用上一根收盘价补齐。
- 限流：遇到 HTTP 418/429 时所有请求线程一起退避；重同步失败按指数退避重试，不会阻塞其他合约。
- 合约列表：每小时刷新一次，新上市的合约自动加入，已下架的自动移除。
- 仅访问币安**公开行情**，不使用API Key、无账户权限、不会自动下单、不会保存交易明细。

**提醒**：

- 不是说EMA21和EMA50完全相等才发信号。精确浮点数为零很少出现，默认筛选 `|DIF%| <= 0.020%`，页面可以调整阈值。
- 刚上市的合约可能没有210根完整5分钟K线，无法正常计算EMA200，会被略过；已跳过数量会显示。
- 部分不活跃合约可能没有持续交易，因此最新K线时间会略旧。不要把过时数据当作即时信号。
- 全球各地对币安 API 的网络访问可能不同。如果交易所服务在当前网络不可用，页面会显示连接异常；程序不能绕过当地法律或限制。
- DIF金叉、死叉是行情辅助信号，不能保证盈利，特别是杠杆合约存在显著风险。

## 技术说明

`EMA(L) = EMA_previous + 2/(L+1) * (price - EMA_previous)`，历史上从首根收盘价初始化（部分看盘软件用 SMA 作起点，499 根之后残余差异约 0.7%，对 DIF 影响很小）；K线未收盘时使用最新K线价对上一根**已收盘**EMA作临时计算，**不**把盘中每个tick累加为新EMA。这样的算法可以避免一根K线内多次采样导致EMA计算错误。
