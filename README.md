# 币安合约 5 分钟 DIF 实时监控

实时扫描所有**交易中的永续合约**（默认 U 本位 + 币本位），计算：

- `EMA21`、`EMA50`、`EMA200`，均基于**5分钟收盘价**。
- `DIF = EMA21 - EMA50`。
- 价格归一化 `DIF% = (EMA21 - EMA50) / 最新价 × 100%`，用于不同币价之间的筛选。
- **盘中金叉 / 死叉**：当前**尚未收盘**的5分钟K线，DIF已经越过零轴；可能反复改变。
- **确认金叉 / 死叉**：5分钟K线已收盘，DIF相对前一根已收盘K线越过零轴。最近5分钟的确认信号可见。
- 价格高于还是低于 EMA200，用于辅助判断趋势；原有行情列表不强制过滤，提前预测默认开启趋势过滤。

## 提前1—2根5分钟K线预测

列表新增 **金/死叉概率 · 1/2根内** 列，默认打开 **提前预测**，也可以单独选择 **预测金叉**、**预测死叉**，用“预测窗口”选择1根（5分钟）或2根（10分钟）。原有接近零轴、盘中和收盘确认筛选继续保留。

预测只使用已收盘 K 线。默认将最新三根 EMA21、EMA50 的变化量按 **0.5 / 0.3 / 0.2** 加权，以相对斜率外推：

```text
未来 n 根 DIF ≈ 已收盘 DIF + n × 加权(EMA21斜率 − EMA50斜率)
eta = −已收盘 DIF / 加权相对斜率
```

窗口从观察收盘时刻开始，包含当前进行中 K 线；不足1根/2根预计严格跨零才进入相应列表。两条线同时上涨也可以预示死叉，同时下跌也可以预示金叉。默认开启 EMA200 趋势过滤（金叉要求已收盘价高于EMA200或EMA200上升；死叉对称），要求 `0.0001% ≤ |DIF / 已收盘价| ≤ 0.05%`，高波动时缩短 eta 上限至1.2根。页面“预测设置”可以调整过滤、三个斜率权重、样本半衰期、模型和刷新周期，并保存到本机；保存后旧配置百分比停止展示，后台重新验证。

**百分比是交叉事件的历史估计，不是盈利概率。** 1根表示下一根收盘跨越，2根表示接下来两根至少一次收盘跨越，包含1根事件；触及零轴不算严格跨越。不保证每次交叉都会提前提示，没有止盈止损、账户或下单功能。

- 特征包括归一化DIF、EMA绝对/相对斜率、eta、距EMA200、EMA200斜率、12/48根收益波动率、波动率比、距上次交叉、斜率加速度与相对成交量。盘中tick不更新这些已收盘特征。
- 默认模型是 **分层频率 + 校准逻辑回归**。逻辑回归使用训练段内部更早数据拟合、较晚数据校准，中间剔除跨边界结果；训练/校准或正负类别不足则退回频率。可以单独选择频率或逻辑回归。纯Python实现，无需安装 sklearn。
- 同币、同方向、eta分桶及相近波动状态优先；不足时退回不区分波动状态的较粗桶（会单独验证）。跨币先验只借用**同市场、同配置**、最多64个近期缓存合约，且结果必须在本次训练边界之前。先验需有效≥60例、至少3个其他合约，本币仍需有效≥10例；不借先验需有效≥30例。样本按默认7天半衰期指数加权并平滑，防止小样本100%。
- 最终按日历时间前80%训练、后20%独立验证；两根结果跨界的训练样本剔除。相似条件后段验证≥10例、平均校准偏差≤15个百分点，且Brier不明显差于固定概率基线（容差0.01），才显示百分比。分类器特征偏离训练均值超过5个标准差也不展示。
- 候选后台补充最多10000根真实历史（约34.7天），单线程、最多8个排队、分页节流。默认每60分钟刷新，缓存存在时增量补拉；失败按同一周期重试。超过默认72小时模型年龄停止展示百分比；等待刷新期间仍合格的旧模型以低可靠度显示。可配置周期与最大年龄。
- 缓存在项目目录 `forecast_cache/`，包含带版本和配置指纹的JSON模型、真实历史、配置与最多200条预测记录，使用原子替换写入；没有API密钥或账户数据。重启优先恢复匹配配置的缓存。未完成的预测在重启、重同步或EMA重新基准化时作废，不补造命中结果。
- 悬停概率查看有效训练数、先验合约数、独立验证命中率、最近20次同类预测命中率、年龄、波动状态、逻辑回归特征贡献和“—”的具体原因。最近20次按同方向+eta桶+配置统计，未满20次显示“—”；仅记录页面轮询实际观察到的候选，每根去重，窗口可能重叠。若这20次已展示概率的校准偏差超过25个百分点，暂停概率直到该条件解除或新记录替换。可靠度高/中/低是样本量与验证偏差的规则分级，不是真实概率的置信等级。
- 验证命中率区间改为按UTC日块重采样的95%描述区间，至少5天才显示；保留日内相关性但未消除跨日依赖，不是下一次真实概率的置信区间。
- 断线、同步中、行情超过90秒未更新、连续真实历史不足210次EMA更新或观察收盘已超过5分钟，停止展示预测。原有行情EMA允许补齐无成交K线；**预测、标签与高周期特征不使用合成K线**，遇缺口重新预热。
- 可选15分钟/1小时确认由完整连续5分钟K线聚合，仅在高周期收盘时更新，需100根高周期预热（1小时约1200根5分钟数据）；候选预热不足会触发后台补拉。相对成交量是本根成交量/此前20根均量，缺量时不能通过成交量过滤。

### 滚动报告与离线评估

页面“滚动验证报告”显示每个已训练合约的精准率、误报率、假阳性率、信号密度、提前1/2根分布与Brier。扩展窗口三折：前40%→随后20%、前60%→随后20%、前80%→随后20%；每折训练和跨币标签严格剔除边界后的数据。

报告分别统计几何候选及两根概率≥50%的原始模型信号；滚动结果不使用验证段结果事后筛信号，因此与最终通过独立门槛才展示的实时概率有区别。密度分母是固定不重叠三根观察网格，不是所有K线。旧单根斜率与新规则全历史对照只是描述统计，不能证明新规则样本外更优。未取得真实行情回测前，不宣称准确率提升或稳定盈利。

```bash
python -m unittest discover -s tests -v
python backtest_forecast.py candles.csv --output forecast-report.json
# 可选完整或部分配置JSON
python backtest_forecast.py candles.csv --config forecast-config.json --output forecast-report.json
```

CSV必需列 `open_time,close`，时间为对齐5分钟的Unix毫秒，可选 `volume,high,low`，至少213根不同时间的已收盘数据；实用评估建议足够长、覆盖多种市场状态。CSV不会自动判断交易所是否已收盘，需由使用者确保。离线单币报告不借跨币先验。运行页面交互测试：`npm install --no-save jsdom@30.1.2 && node tests/test_dashboard.cjs`（仅开发验证需要Node 20.19+）。

实施范围与算法边界见 [实施说明](docs/forecast-implementation.md)。资金费率、GBDT和参数在线学习未启用；当前在线部分仅记录验证结果并监测漂移。

## 启动方法

1. 下载ZIP并解压到一个文件夹。电脑安装 Python 3.10 或更高版本。
2. 在终端（Windows 用 PowerShell 或 CMD）切换到解压后的本文件夹，执行：

```bash
python -m pip install -r requirements.txt
python binance_live_dif.py
```

3. 浏览器打开 `http://127.0.0.1:8765`，**无需刷新网页**。
4. 关闭监控：终端按 `Ctrl + C`。

可选：只看 U 本位 / 币本位，或更改端口：

```bash
python binance_live_dif.py --market um
python binance_live_dif.py --market cm
python binance_live_dif.py --port 8888
```

## 运行原理

- 启动时：REST 获取永续合约名单，每个合约获取499根5分钟K线，以便计算EMA200，并显示初始化进度。
- 历史载入期间：逐批建立 WebSocket 订阅（不是反复下载CSV/Excel）。
- 运行时：币安有新的K线数据就重新计算**盘中临时 DIF**；K线收盘 `x=true` 后再计算确认信号。
- 浏览器：**每2秒**读取本机实时状态。网页版无需重新打开或按刷新。
- 网络断线：WebSocket 自动重连；若有错过的整根5分钟K线，会使用REST重新同步，以免假信号。
- 时钟校准：启动时读取币安服务器时间，用它判断K线是否收盘，本机时钟快慢不会影响EMA。
- 无成交的K线：币安不返回没有成交的5分钟K线，程序按图表软件的做法用上一根收盘价补齐。
- 限流：遇到 HTTP 418/429 时所有请求线程一起退避；重同步失败按指数退避重试，不会阻塞其他合约。
- 合约列表：每小时刷新一次，新上市的合约自动加入，已下架的自动移除。
- 仅访问币安**公开行情**，不使用API Key、无账户权限、不会自动下单、不会保存交易明细。

**提醒**：

- 不是说EMA21和EMA50完全相等才发信号。精确浮点数为零很少出现，默认筛选 `|DIF%| <= 0.020%`，页面可以调整阈值。
- 刚上市的合约可能没有210根完整5分钟K线，无法正常计算EMA200，会被略过；已跳过数量会显示。
- 部分不活跃合约可能没有持续交易，因此最新K线时间会略旧。不要把过时数据当作即时信号。
- 全球各地对币安 API 的网络访问可能不同。如果交易所服务在当前网络不可用，页面会显示连接异常；程序不能绕过当地法律或限制。
- DIF金叉、死叉是行情辅助信号，不能保证盈利，特别是杠杆合约存在显著风险。

## 使用接口

- U本位公开 REST `https://fapi.binance.com/fapi/v1/klines` 和 `exchangeInfo`。
- U本位 2026 新 WebSocket `wss://fstream.binance.com/market/stream`。
- 币本位公开 REST `https://dapi.binance.com/dapi/v1/klines` 和 `exchangeInfo`。
- 币本位 WebSocket `wss://dstream.binance.com/stream`。

## 技术说明

`EMA(L) = EMA_previous + 2/(L+1) * (price - EMA_previous)`，历史上从首根收盘价初始化（部分看盘软件用 SMA 作起点，499 根之后残余差异约 0.7%，对 DIF 影响很小）；K线未收盘时使用最新K线价对上一根**已收盘**EMA作临时计算，**不**把盘中每个tick累加为新EMA。这样的算法可以避免一根K线内多次采样导致EMA计算错误。
